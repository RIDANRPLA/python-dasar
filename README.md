A practice repository for learning Python fundamentals, based on the
Santrikoding "Belajar Python Dasar" tutorial series (19 chapters). Every
chapter gets its own commit and is pushed to GitHub as soon as it is done.

## What is covered

- Fundamentals: program structure, comments, indentation, data types,
  variables, constants, and operators.
- Logic: if/elif/else, for and while loops, break and continue, plus
  functions that use default arguments, *args, and **kwargs.
- Data structures: list, tuple, set, and dictionary.
- Object-oriented programming: classes and objects, encapsulation,
  inheritance, polymorphism, and abstraction using ABC.
- Writing reliable programs: handling errors with try, except, else,
  finally, and raise; reading and writing files using the with statement.
- Organizing code: custom modules, built-in modules, and packages that
  use __init__.py.
